# p1 - Express.js CRUD API

This folder contains code for my MERN (p) project.  
It demonstrates a simple **CRUD (Create, Read, Update, Delete)** API built with **Node.js and Express.js**.
- Designed for testing with Postman or similar API clients.  
- Supports adding multiple items and performing full CRUD operations.  


## API Functionality

- **POST /items** → Add new items (e.g., Item One, Item Two, Item Three).  
- **GET /items** → Retrieve all items currently stored.  
- **PUT /items/:id** → Update an existing item by its ID.  
- **DELETE /items/:id** → Remove an item by its ID.
